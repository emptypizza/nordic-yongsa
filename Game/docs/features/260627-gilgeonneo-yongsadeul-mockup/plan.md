# 길건너용사들 — 비주얼 목업 구현 계획

기존 `260614-grail-escort-prototype`(성배 호위 코어)를 **Crossy Road식 레인 보드 +
성배마차 호위 RPG '길건너용사들'** 로 진화. 목표는 `mokup1.png` 비주얼에 최대한 근접한
**플레이 가능한 목업**. 단일 진실 문서는 `260614-grail-escort-prototype/design.md`이며,
구조 변경은 그 문서에 동기화한다(이 폴더는 이번 마일스톤 계획서).

## 0. 레퍼런스 분석

- **`mokup1.png` (1차 타깃)**: 세로 모바일. 러시 그린 레인 보드 위에
  - 가로 레인 밴드: 잔디 여러 줄 + **파란 강(통나무 떠다님)** + 길.
  - 맨 끝 **빛나는 파란 포탈**(골). 중앙에 **성배마차(나무 마차)**, 집·대장간(불).
  - 초록 오크/고블린 적, 캠프파이어, 가장자리 나무·덤불·바위.
  - 중앙 하단 영웅(검사)이 하이라이트 타일 위, "DRAG TO MOVE".
  - 상단 HUD: `Guardian, HQ` + 초록 XP바 + 레벨(★80), 중앙 큰 스코어 `72` + `⚔BEST 125`,
    우측 코인 `342` + 일시정지. 하단 영웅 카드 3장 `라비/소희/아론`(Lv1) + `편집`.
- **KakaoTalk 스프라이트시트**: 흰머리 검사(파란 망토+검) 풀 애니. = 플레이어 영웅(이미 `Test Ch.glb`).
- **690929…jpg**: 플랫 핸드페인트 톱다운 아트 스타일(러시 그린, 캠프파이어, 토템) — 색·무드 레퍼런스.
- **mainmenu.png**: 「메그러스 스토리 ~도터의 모험~」 보xel 타이틀 아트. 주인공/동료 톤.

## 2. 목업 격차 → 구현 항목

mokup1.png에 맞추기 위한 신규/변경 (프로젝트 규칙 준수: 액터는 코드-빌드, 메시는 자식 노드,
프리미티브 placeholder로 끝까지 → 추후 .glb 교체).

1. **레인 타입 시스템** — `LaneConfig.gd`: 행(z)마다 `GRASS | RIVER | PATH` 결정(결정론적).
   강은 1~2칸 폭 밴드 1~2개. 포탈 골 직전은 안전 잔디.
2. **러시 보드** — `Board.gd`: 레인별 색 타일(잔디 명암 교차, 파란 물, 흙길) +
   가장자리 장식(나무=원뿔+원기둥, 덤불=구, 바위=박스) + **빛나는 포탈 골**(토러스+발광 코어).
3. **강 통나무 + frogger** — `Log.gd`: 물 레인 위를 x축으로 드리프트(레인별 방향/속도, 화면 밖 래핑).
   플레이어가 물 타일에 있고 통나무 위가 아니면 **익사**(HP 차감 후 시작점 리셋),
   통나무 위면 함께 떠내려간다. (Crossy Road 시그니처)
4. **성배 = 마차(馬車)** — `Grail.gd` 비주얼만 교체: 나무 몸체+캐노피+바퀴(굴러가는 회전)+
   상단 발광 성배. 로직(자동전진/HP/무적/Win) 불변. 마차는 물 면역(마법 호위 대상).
5. **HUD 목업** — `Hud.gd` 리디자인: 상단바(Guardian/HP·XP바/스코어/BEST/코인/일시정지),
   하단 영웅 카드 3장(`라비/소희/아론` + Lv 배지 + 선택 하이라이트) + `편집`. 스와이프/d-pad 유지.
6. **영웅 로스터** — `HeroRoster.gd`: 라비/소희/아론(이름·테마색). HUD 카드 + 선택 영웅 틴트.
7. **무드 라이팅** — 따뜻한 태양광 + 하늘 그라데이션 + 부드러운 앰비언트(러시 그린 강조).

## 3. 스코어/진행 (목업 수치)

- **스코어** = 성배마차가 전진한 행 수(`72`처럼 상단 중앙 큰 숫자). `BEST`는 세션 최고.
- **코인** = 적 처치 시 누적(상단 우측). HP는 상단 좌측 바.
- 클리어/실패 로직은 기존 유지(포탈 도달=ARRIVED, HP 0=FAILED).

## 4. 작업 순서

1. `plan.md`(본 문서) → 2. `LaneConfig`+`Board`(레인/장식/포탈) →
3. `Log`+Player 물/통나무 → 4. `Grail` 마차 + `HeroRoster` →
5. `Hud` 리디자인 → 6. `design.md` 동기화 + `LogicTests` 보강.

## 5. 검증

- `godot --headless --path Game res://Tests.tscn` → `[selftest] ALL PASS`(레인/물/통나무 래핑 테스트 추가).
- `godot --headless --path Game res://Main.tscn --quit-after 600` → exit 0, 스크립트/파스 에러 0
  (적 스폰·전투·강 통나무 드리프트·마차 전진까지 실행).
- 실제 비주얼/손맛은 에디터 F5.
